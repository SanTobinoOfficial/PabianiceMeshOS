# client

Szkielet aplikacji mobilnej. Na razie tylko interfejs BLE do rozmowy z urządzeniem
(patrz rozdz. 9.4 planu - urządzenie gada z telefonem po BLE albo USB-C, a lista
kontaktów/historia/ustawienia żyją w aplikacji, nie na samym urządzeniu poza
opcjonalnym wyświetlaczem statusu).

Reszta (UI, lista kontaktów, historia wiadomości) - później, po ustabilizowaniu
firmware i formatu komunikacji BLE.
